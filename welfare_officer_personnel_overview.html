Bulk Import Personnel from Excel

Upload an .xlsx file using the same personnel field names as the individual Add Personnel form.

Maximum 5 MB and 2,000 personnel rows per upload. Existing Personnel IDs are skipped rather than overwritten.

Required Excel column names:
personnel_id, full_name, rank_designation, unit, department, posting_location, joining_date, email, phone, employment_status, initial_password
Important: initial_password must contain at least 8 characters. The server hashes it before storing it in PostgreSQL. Use the Excel file only as a controlled temporary import file.
